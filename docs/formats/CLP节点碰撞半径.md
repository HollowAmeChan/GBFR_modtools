# CLP 节点碰撞半径

## 结论

CLP 的 `thick_` 不是骨链线宽，也不是 CLH 的重复数据。它是每个动态节点参与碰撞时使用的半径。预览应在节点当前位置画半径为 `thick_` 的球形线框；CLH 继续按自身 `radius` 画球或胶囊。节点靠近 CLH 时，看到的有效间隔应同时考虑这两个半径，而不能只看绿色中心线到青色 CLH 表面的距离。

当前没有证据证明相邻 CLP 节点之间的整段骨链也是胶囊碰撞体。CLP 节点记录只有一个位置来源和一个 `thick_`，没有类似 CLH `capsule` 的第二端点或形状引用。因此预览只画可以由文件直接恢复的节点球，不把骨链段额外扩成胶囊。

## 文件与程序证据

游戏 EXE 中的 CLP 节点解析函数位于当前版本的 `0x142343190..0x14234393D`。节点记录步长是 `0x60`，字段字符串与写入顺序为：

```text
dataVersion_, no, noUp, noDown, noSide, noPoly, noFix,
rotLimit, friction, gravityBlendRate_, offset, originalRate_,
weight_, thick_, windForceArea_, jointScale_,
bAllowChangeScale_, axisAdjustRate_
```

`thick_` 被转换为单精度浮点并写入节点记录偏移 `+0x1C`。随后解析 `windForceArea_` 时，加载器会用 `thick_` 作为缺省值，并把运行时风面积保存为 `windForceArea_ - thick_`；`thick_` 本身仍保留在独立字段中。这排除了它只是风面积别名的可能。

全角色 CLP 样本也支持半径语义：玩家角色 `thick_` 的常见值集中在 `0.01..0.04`，总体可到 `0.08`，通常沿链从根部向末端增大。这个范围和 CLH `radius` 的量级一致。当前 `pl1400` 自定义裙摆链使用 `0.005, 0.010, 0.015, 0.025, 0.030, 0.035`；同角色大腿附近 CLH 半径约为 `0.063..0.080`。因此裙摆中心线在青色碰撞表面之外仍多留约 `0.035` 的距离，与实机观察一致。

## 预览契约

- 绿色直线：CLP 拓扑约束，只表达节点连接。
- 紫色球：CLP 节点的 `thick_` 碰撞半径。
- 青色球/胶囊：CLH 的 `radius` 与 `capsule` 形状。
- `thick_ <= 0` 的节点不画球。
- CLP 节点球和 CLH 碰撞体使用独立显示开关，便于比较中心线、节点包络和外部碰撞体。

以上确认了节点半径及其可视化方式。求解器是否还会对相邻粒子做连续扫掠、是否存在未编码在 CLP 节点中的额外骨段碰撞，仍需要更深的运行时调用链或实机对照才能确认；当前预览不把这部分推断画成已知形状。
