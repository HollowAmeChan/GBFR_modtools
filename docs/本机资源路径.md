# 本机资源路径

本文集中记录本项目当前使用的本机输入、工作区、工具和研究输出。路径只描述这台开发机的布局，不属于游戏格式契约；换机器后应先更新本文，再运行研究脚本。

## 游戏原始数据（只读）

| 用途 | 路径 |
|---|---|
| 游戏安装目录 | `D:\Steam\steamapps\common\Granblue Fantasy Relink` |
| 原始归档索引 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data.i` |
| 原始归档分卷 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data.0` 至 `data.11` |
| 完整游戏数据 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data` |
| DXBC Shader | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\shader` |
| 游戏主程序 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\granblue_fantasy_relink.exe` |

研究脚本只读这些文件。不要在游戏安装目录中生成 JSON、CSV 或反汇编结果。

完整数据中与当前模型、材质和 Shader 研究直接相关的根目录如下：

| 资源 | 路径 |
|---|---|
| 角色模型、骨架、MMAT、SOP | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\model` |
| 流式 LOD 网格 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\model_streaming` |
| 角色动画和 cloth | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\pl`、`data\fp`、`data\wp` |
| Granite 解包贴图 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\granite` |
| 普通 `.texture` 资源 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\texture` |
| Shader 阶段目录 | `D:\Steam\steamapps\common\Granblue Fantasy Relink\data\shader\{vs,ps,cs,hs,ds,lighting,render,compute}` |

`data.i` 与 `data.0` 至 `data.11` 是 GBFRDataTools 的原始解包输入；`data\` 是当前已完整解包、供全量统计和抽样验证的只读输入。MMAT 扫描必须以整个 `data\` 为根，不能只从奶刀工作区推断全游戏规律。

角色 MMAT 位于 `data\model\<pl|fp|wp>\<模型 ID>\vars\<配色>.mmat`。奶刀的默认身体和头部材质分别从 `source\data\model\pl\pl1400\vars` 与 `source\data\model\fp\fp1400\vars` 取样；编辑器预览相同相对路径下的 `unpack` JSON，最终游戏文件写入 `build`。

`C:\tmp` 下的源码和探针属于临时材料，不能作为唯一研究记录。可复现逻辑应迁入 `scripts/research`，结论应迁入 `docs/formats`。

工具表中以 `GBFR_modtools\` 开头的路径均相对于 C++ 仓库根目录，不是相对于 `gbfrMod` 根目录。`out\` 可由构建重新生成；`C:\tmp\GBFRDataTools-latest` 可能被清理，因此正式 schema、必要源码引用和研究脚本必须保存在仓库内。
