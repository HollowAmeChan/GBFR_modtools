对于msk的制作
> msk1不会做就默认 0.5 0.5 1 1(粗糙度 厚度 固定阴影 次级AO)
> 脸部msk1不会做默认 0 0 1 1(特效1 特效2 AO 未知白)
> 脸部msk2不会做默认 1 0 0 1(未知白 未知黑 未知黑 正面遮罩建议做)
> msk3不会做就默认 0.5 1 1 1(曲率 内描边遮罩 未知白 未知白)
> 脸部msk4不会做就默认0 1 0 1(未知黑 未知白 b为腮红遮罩，腮红为白 未知黑 未知白)
> 脸部msk5不会做就默认0.5 0 0 1(r为描边宽度遮罩 ，可以给眼眶嘴全黑 未知黑 未知黑 未知白)

物理：
绳索预设比较硬
裙摆预设比较硬
长发稍微软
辫子非常软（做各种东西都合适，包括裙子）

头发建议直接放本来就放头发的部分

clp层的回弹力关乎碰到碰撞体后回正的力度
0就比较快了，1非常快
-1稍柔和，不要尝试低于-1mesh会甩不见。头发建议-1

空气阻力改小会回弹的更慢
头发建议0.5

头发角度限制建议默认的辫子梯度
裙子角度限制可以开固定60

不要删任何原本就有的骨骼

clp物理层clh碰撞层，clh中还有碰撞体
clp物理层有整体参，能添加骨骼解算链，尽量不要删clp中旧的布料连接
clp会引用clh碰撞层，看上去可以修改引用开关
clh中的碰撞体也尽量不要删除，可以直接半径改0，不过有一部分可以删（也有可能全可以删）
这些都是因为mot动画可以覆盖物理导致的，因为他可能会空指针

可以完全删除一个材质内的mesh，不能删除材质，可以使用材质指定功能（导出时有优化）

骨骼000,003都是可以动的，头的根骨也是可以移动的，只是要对得上身体，根骨动过以后得全部动画换基导出，如果体型差不多身体根骨不用动，是不需要手动改动画的，头这种基本全都要改动画
ui图片里面都是dx7 线性保存的，同时尽量不要改分辨率大小，改了可能会进游戏有分块显示不出来
别的颜色图就正常是dx7 srgb，msk是dx7线性就行，这俩这么存没啥问题

测试动画时，有的动画会禁用碰撞组，所以可能会穿模，同时有的动画会把布料k进去所以他们会故意禁用
